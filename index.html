Автосохранение в репозиторий GitHub

Почему изменения не сохранялись на GitHub: статическая HTML-страница на GitHub без токена сохраняет оценки только в память текущего браузера. Подключите токен один раз — журнал сам будет записывать изменения прямо в ваш репозиторий!
  1. Откройте на GitHub: Settings → Developer settings → Personal access tokens → Tokens (classic) (или Fine-grained tokens).
  2. Создайте токен с правом repo (или Contents: Read and write для репозитория журнала).
  3. Вставьте токен ниже — он сохранится только в памяти вашего браузера и не попадёт в открытый код на GitHub.
